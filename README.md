## 🚀 Main Project

### CraftConnect

CraftConnect is a full-stack service marketplace platform that connects customers with skilled craftsmen.

**Main Features:**
- Role-based dashboards for customers, craftsmen, admins, and super admins
- JWT cookie authentication
- Email OTP verification
- Customer task booking
- Automatic craftsman assignment
- Task timeout and reassignment system
- Notifications
- Reviews and ratings
- Admin moderation and warnings

**Tech Stack:**  
React, Tailwind CSS, Material UI, Node.js, Express.js, Prisma ORM, PostgreSQL, JWT, Axios
